Privacy policy

This policy covers PiNAS Drive Backup, the account owner’s personal Google Drive backup application.

Google data accessed and used

With the owner’s authorization, the application reads Google Drive file contents and metadata through the drive.readonly permission. It uses this information to create and update a local backup and to create recovery snapshots. It does not request permission to change or delete files in Google Drive.

Storage and protection

Downloaded files are stored on the owner-operated NAS. Recovery snapshots are encrypted by restic. The downloaded mirror itself is not represented as encrypted at rest. Google authorization tokens are stored in access-restricted configuration on the backup system, not on this website. Operational logs can contain filenames, timestamps, and error details.

Sharing

The backup application does not sell Google user data, use it for advertising, or use it to train artificial intelligence models. It has no feature for distributing backup contents to other users. Backup files and recovery snapshots remain on owner-managed storage. If configured, an external job-health service receives completion or failure signals rather than file contents.

Retention and deletion

The local file mirror is retained until the owner removes it. A deletion guard can retain local copies of files removed from Drive. Recovery snapshots follow the configured retention policy and can retain previous file versions. Revoking Google access stops future access but does not erase existing local copies. The owner can delete local copies, recovery snapshots, and credentials from the storage they administer.

Control and revocation

The owner can stop scheduled jobs and revoke access in Google Account connections. Reconnection requires Google approval.

Google API Limited Use

PiNAS Drive Backup’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website and contact

These information pages have no sign-in form, backup upload feature, analytics scripts, or cookies set by the page code. GitHub Pages hosts the website and may process ordinary request data under GitHub’s privacy statement. Contact the support email displayed on the Google consent screen, or use the repository issue tracker without posting private information.
